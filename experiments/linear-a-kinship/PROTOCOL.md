# Kinship formula feasibility inventory

## What is done

- Source-backed positive and negative Linear B development fixtures for parentage.
- Literal marker inventory in pinned DAMOS, retaining raw lines and object IDs.
- Ordered graphic shapes in strict-source Linear A tablets: one, two or three word
  runs followed by numeral 1 or 2. These are graphic WORD slots, not names.

## Why

The Etruscan scaffolding prototype receives manually supplied entity spans and known
name morphology. Neither input is established for the Linear A slots considered here.

## Mechanics

```text
Audit the known-language examples and preserve relation direction
Inventory exact marker tokens, retaining editorial notation
Reject conflicting or uncertain Linear A records
Keep graphic word order and repeated slots within each physical text line
Record shapes with counts 1 or 2, without assigning a kinship meaning
```

The description is development exploration, not a hypothesis test. The shape restriction
is inspired by the inspected Linear B examples, not tuned against Linear A hits. No p-value,
semantic score, language identification or gender inference is permitted. No gate is passed.
The parser does not model attached patronymics or line-wrapped expressions, and therefore
cannot establish absence of parentage. PY An654 explicitly shows why line wrapping matters.
One-sign logograms use the existing aggregate role table (>=.8); ambiguous roles remain a
limitation. Output includes sign IDs, raw text, parent object and line index; no guessed sounds.
All faces remain one independent object. Corpus source conflicts exclude the entire record;
HT117a must be reported separately as an interesting but conflicted example, not silently fixed.

Known control outcomes are supplied annotations, not predictions. A future recovery study
needs additional independent positive objects and negative relations (ownership, occupation,
place affiliation, ordinary pairing), whole-object splits and shuffled within-context names.
It must separately evaluate named child-parent edges, unnamed relatives and collective
children. No requirement for two explicit names should force a daughter to acquire a name.
